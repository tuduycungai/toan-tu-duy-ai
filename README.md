# Tu_duy_Tu_giac_AI_Tutor_V6

## Nâng cấp từ V15 theo báo cáo nghiên cứu Chatbot Gia sư Tứ giác V16

Phiên bản V6 triển khai các nguyên tắc:
- Analysis First: phân tích đề trước khi hướng dẫn.
- Backward Reasoning: phân tích ngược từ kết luận.
- Solver Verification Loop: kiểm tra khung lời giải trước khi hỏi học sinh.
- Socratic One Question: mỗi lượt một câu hỏi.
- Adaptive Hint H0–H4.
- Anti Full Solution: không làm bài thay học sinh.

## Triển khai
npm install
npm run build

Biến môi trường:
GEMINI_API_KEY
GEMINI_MODEL
ACCESS_CODE

Không đưa khóa API vào mã nguồn.
